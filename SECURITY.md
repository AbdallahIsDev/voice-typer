# Security Policy

## Supported Versions

Voice Typer is a desktop application. Security fixes are applied to the latest
release only.

| Version | Supported          |
|---------|--------------------|
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
GitHub issue. Instead:

1. Email the maintainer directly via GitHub's private vulnerability reporting:
   https://github.com/AbdallahIsDev/voice-typer/security/advisories/new
2. Include a description of the vulnerability and steps to reproduce.
3. You will receive a response within 72 hours.

## Security Architecture

Voice Typer is designed with the following security boundaries:

### IPC Authentication (SEC-018)

The TCP IPC server (port 9876) requires a per-session authentication token.
The token is generated by the Electron main process and passed to the Python
backend via the `VOICE_TYPER_IPC_TOKEN` environment variable. No other local
process can connect to the IPC port without this token.

### Command Allowlist (SEC-019)

The Electron main process enforces an allowlist of IPC commands. The renderer
cannot invoke arbitrary commands — only the ~35 commands in `ALLOWED_COMMANDS`
are forwarded to the Python backend.

### Secret Redaction (SEC-003)

API keys (OpenAI, Groq, Deepgram, LLM) are never sent to the renderer in
cleartext. The `get_config` IPC response redacts secret fields to a
`<redacted>` sentinel, so the renderer can show "key configured" without
ever receiving the key value.

### URL Allowlist (RELIABILITY-004)

Cloud ASR and LLM polish calls are restricted to a URL allowlist. Untrusted
URLs are rejected before any network request is made, preventing SSRF and
data exfiltration to attacker-controlled endpoints.

### Payload Size Limits (SEC-008, SEC-010, SEC-011)

- TCP receive buffer capped at 4 MB per message.
- History limit/offset bounded to prevent DoS via huge values.
- Vocabulary payload capped at 1 MB; individual values at 1024 chars.

## Known Limitations

- **Local IPC only:** The TCP server binds to `127.0.0.1` (loopback). It is
  not reachable from other machines on the network.
- **No TLS:** The IPC connection is unencrypted. This is acceptable because
  it's loopback-only, but means any local process with the session token can
  intercept traffic.
- **Autostart:** The installer enables autostart by default (Windows
  Scheduled Task). Users can disable it via the tray menu.
